Switch the built-in icons from Tabler Icons to Phosphor Icons, following the new graphical profile. Status icons in `scout-callout` use the fill weight, and small functional icons (chevrons, check, close, arrows, spinner) use the bold weight. Consumers can keep passing any `currentColor` SVG string as an icon, but we now recommend `@phosphor-icons/core`.
